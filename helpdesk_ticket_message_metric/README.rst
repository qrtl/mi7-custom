This module does the following:

- Adds ``first_reply_date`` field to helpdesk.ticket to track the date
  of the first reply sent to the customer by an internal user.
- Adds ``interaction_count`` field to helpdesk.ticket to count the
  number of customer-facing messages on the ticket.
